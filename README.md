# Llavero: landing

Página estática de presentación de [Llavero](https://github.com/briann39/Llavero). Sin dependencias ni paso de compilación: HTML, CSS y un poco de JavaScript. Las tipografías van incluidas en `fonts/`, así que funciona sin conexión.

## Verla en local

Abre `index.html` con doble clic, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Publicarla

Es una carpeta de archivos estáticos: sirve GitHub Pages, Netlify, Cloudflare Pages o cualquier hosting.

## Qué editar

- Textos y enlaces: `index.html`. Los botones de descarga apuntan a `https://github.com/briann39/Llavero/releases/latest`, que no existirá hasta que publiques una Release.
- Colores y tipografía: variables al principio de `css/estilos.css` (siguen el tema claro u oscuro del sistema).
- La llave interactiva: `js/llave.js`.
- La maqueta de la app es HTML y CSS con datos ficticios, no una captura. Si cambias la interfaz de Llavero, actualízala a mano.
