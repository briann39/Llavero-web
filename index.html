Tus contraseñas, bajo llave.

Llavero es un gestor de contraseñas para Windows que lo cifra todo en tu propio equipo. Sin cuenta, sin servidor y con el código a la vista.

Descargar para Windows Cómo las protege

Gratis y de código abierto (MIT). ¿Prefieres no instalar nada? Úsalo en el navegador.

Es solo una demostración. Lo que escribas no se envía ni se guarda en ningún sitio.

Solo sale de tu equipo lo que ya está cifrado

Llavero usa las funciones criptográficas estándar del sistema, sin inventar nada propio. Tu contraseña maestra es la única llave, y no se guarda en ninguna parte.

Sucede dentro de tu equipo

Tu contraseña maestra

La escribes al abrir Llavero. No se guarda ni se envía a ningún sitio.

Se convierte en una clave

PBKDF2 con 600.000 vueltas y una sal aleatoria. Probar contraseñas a la fuerza sale muy caro.

Cada entrada se cifra

AES-256-GCM con un valor nuevo por entrada. Si alguien altera los datos, no se abren.

Solo sale lo cifrado

A tu disco, a una copia de seguridad o a la nube si la activas. Sin tu contraseña, es ilegible.

Una lista que se lee de un vistazo

Cada categoría lleva su capucha de color, como las llaves de un manojo. Pasa el ratón por una fila para copiar la contraseña sin abrir nada, y mira el código 2FA sin salir de la lista.

Protegerlas

Códigos 2FA integrados
Genera los códigos de un solo uso (TOTP) y los muestra en la lista, con cuenta atrás.
Auditoría de seguridad
Detecta contraseñas repetidas, débiles, antiguas o filtradas. La comprobación de filtraciones usa Have I Been Pwned y solo envía 5 caracteres del hash, nunca la contraseña.
Bloqueo automático
Se cierra tras 5 minutos sin actividad, y el portapapeles se borra a los 20 segundos de copiar.
Clave secreta opcional
Una segunda clave que no sale de tus equipos, con su Kit de emergencia. Robar la base de datos no basta para atacarte.

Usarlo cada día

Generador de contraseñas y frases
Contraseñas aleatorias a tu medida, o frases de varias palabras fáciles de recordar.
Teclado primero
Ctrl K abre una paleta para buscar y actuar sin ratón. Ctrl Alt L abre la búsqueda rápida desde cualquier aplicación.
Siempre a mano
Vive en la bandeja del sistema y puede arrancar con Windows, ya minimizado.
Sin perder nada por error
Historial de contraseñas anteriores, papelera de 30 días y avisos de caducidad para rotarlas a tiempo.
Claro u oscuro
Sigue el tema de Windows o el que elijas. Puedes traer tus datos desde un archivo CSV.

Copias y nube

Copia en un archivo
Un respaldo cifrado que solo se abre con tu contraseña maestra.
Copias automáticas
Elige una carpeta (un disco externo, OneDrive…) y Llavero guarda copias cifradas cada cierto tiempo, conservando las últimas.
Nube opcional con Supabase
Sube solo datos ya cifrados. Cada cuenta ve únicamente lo suyo, gracias a las políticas de seguridad por fila.
Actualizaciones
La app avisa cuando hay una versión nueva en GitHub.

El código es público, para que lo veas con tus propios ojos

Llavero se publica en GitHub con licencia MIT. Puedes leer cada línea de lo que hace con tus contraseñas, en lugar de fiarte de una promesa.

  • Léelo y audítalo El cifrado, el guardado y las copias de seguridad están en archivos que puedes leer. Las pruebas automáticas cubren el cifrado, los respaldos y los códigos 2FA.
  • Úsalo y cámbialo La licencia MIT permite usarlo, copiarlo, modificarlo y compartirlo, también dentro de tus propios proyectos.
  • Compílalo tú mismo Puedes generar la aplicación desde el código en lugar de fiarte del instalador que descargas.
  • Mejóralo Si encuentras un fallo, abre un issue. Si quieres arreglarlo, propón el cambio con una pull request.

Código abierto no significa auditado: ninguna persona externa lo ha revisado todavía. Por eso conviene que lo mires.

Lo que conviene saber antes de usarlo

  • Si olvidas la contraseña maestra, no hay forma de recuperar tus datos. Ni tú ni nadie. Guarda el Kit de emergencia en un lugar seguro.
  • No ha pasado una auditoría de seguridad externa. El código es público precisamente para que cualquiera pueda revisarlo. Revísalo antes de confiarle datos importantes.
  • La aplicación de escritorio es solo para Windows 10 y 11. El instalador no está firmado, así que Windows mostrará un aviso de SmartScreen la primera vez: «Más información» y luego «Ejecutar de todas formas».
  • Tus datos viven en tu equipo, o en tu navegador si usas la versión web. Si pierdes el equipo, reinstalas Windows o borras los datos del navegador sin una copia de seguridad, se pierden con él. Descarga copias cifradas y guárdalas fuera.

Preguntas frecuentes

¿Envía mis contraseñas a algún servidor?

No. Se cifran y se guardan en tu equipo. Llavero no tiene servidor propio. Solo si activas la nube opcional se suben datos, y van ya cifrados con una clave que nunca sale de tu equipo.

¿Cuánto cuesta?

Nada. Es gratuito y de código abierto bajo licencia MIT: puedes usarlo, copiarlo y modificarlo.

¿Puedo traer mis contraseñas de otro gestor?

Sí, desde un archivo CSV, que es el formato que exportan la mayoría de navegadores y gestores.

¿Funciona en Mac, Linux o el móvil?

La aplicación de escritorio es solo para Windows. En otros sistemas puedes usar la versión web, que funciona en cualquier navegador. Sus datos se guardan en ese navegador y no se sincronizan solos con los de otro equipo: para moverlos, usa una copia de seguridad cifrada. No hay aplicación para móvil ni extensión de navegador.

¿Cómo sé que es seguro?

El código está completo en GitHub y el cifrado usa las funciones estándar del navegador (Web Crypto), sin librerías criptográficas propias. Aun así, no ha tenido una auditoría externa, así que la decisión de confiar es tuya.
